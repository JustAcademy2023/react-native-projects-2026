# React Native Projects Every Beginner Should Build in 2026

A playful one page landing site for beginners learning react native. It lists ten react native projects as ten levels, from a simple counter app to a shopping app and a chat app with a backend. The page includes a tappable phone demo, level filters, reading links and Delhi classroom links.

## Live page

After you enable GitHub Pages, the site will be available at:

`https://YOUR-USERNAME.github.io/react-native-projects-2026/`

## What is inside

- `index.html`: the complete landing page. HTML, CSS and a small amount of JavaScript in one file, so there is nothing to install or build.
- `README.md`: this file.

## The ten levels

1. Counter app
2. Tip calculator
3. To do list
4. Notes app
5. Weather app
6. Recipe finder
7. Expense tracker
8. Habit tracker
9. Shopping app with cart
10. Chat or feed app

## Features

- Responsive layout that works from phones to wide desktops
- Pill shaped sticky header with working links
- Interactive counter phone in the hero section
- Filter chips for Starter, Core and Pro levels
- Reading shelf with four blog links
- Ticket style cards for React Native, Flutter, Android and iOS training in Delhi
- Keyboard focus styles and reduced motion support
- SEO friendly title, meta description and Open Graph tags

## Run it locally

Open `index.html` in any browser. No server is needed.

## Publish with GitHub Pages

1. Create a new repository named `react-native-projects-2026`.
2. Upload `index.html` and `README.md` to the main branch.
3. Go to Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and the `/ (root)` folder, then save.
5. Wait a minute, then open your live link.

## Customise

- Colours live in the `:root` block at the top of the style section.
- Level cards are plain `article` elements, so you can edit the text directly.
- All outside links open in a new tab and are easy to find by searching for `justacademy.co`.
